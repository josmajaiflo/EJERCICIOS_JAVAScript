# El Códice de Arkanus

Este proyecto resuelve el problema de interpretar símbolos mágicos usando JavaScript básico.

## Estructura
- **index.html**: página principal.
- **script.js**: contiene la lógica de decodificación.
- **README.md**: descripción del proyecto.

## Ejecución
1. Abre `index.html` en tu navegador.
2. Abre la consola (F12).
3. Verás los resultados de las pruebas con `decodeSpell`.
